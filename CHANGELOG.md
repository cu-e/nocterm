# Changelog

## [4.0.0](https://github.com/cu-e/nocterm/compare/v3.3.0...v4.0.0) (2026-11-10)


### ⚠ BREAKING CHANGES

* hub chats run on the hub and use the agent chat UI; the device-side Cloud code, the node session transport, the session lists and the sessions panel are removed, as is the account server choice. The chat journal format is version 8. workspace::SwapSides is replaced by the Window → Layouts → Swapped sides layout, and Ctrl+E / Cmd+E reach the terminal instead of swapping the side panels.
