# 0048. Original-source guarded raw facts and bounded connection jobs

## Context

Connection views retained native observation admission, persistence and images in
one owner. Committed profile authority must preserve intermediate override/endpoint
history, while cached filesystem handles and equal final settings values cannot
prove the original session or published policy remained current. Windows share
native work capacity and may retain the same session Item after promotion.

## Decision

`nocterm-connections-store::FactsService` owns raw persisted Known observations,
immutable bounded flag results and physical native job admission. Bootstrap supplies
existing DNS, GeoIP, flag and OS ports and its explicit background executor. No
service-to-feature/UI/workspace/native adapter dependency is introduced. Native
workers receive native ports/data only; all GPUI authority checks remain foreground.

Tickets bind the distinct committed profile carrier's incarnation, full endpoint and
independent manual stamps, plus their captured original source lease. The narrow
`ProbeSourceAuthority` synchronously reads the original Item/session capability at
admission and completion. The optional consumer-named `ConnectionFactSession` in
the existing terminal capability carrier supplies one session/ExpectedSession
snapshot from the weak original view Access owner. It adds no broad Item,
ItemHandle or TerminalState method, no FS field to TerminalInfo and no window
lifetime prerequisite. Original close disconnects; promotion preserves the Item. A lease is irrevocable, and observation/history revocation
adds coalesced-transition protection. Source identity is consumer-neutral Item ID
and captured epoch plus exact filesystem capability, not lease allocation or window
cursor lifetime. Reprojection in another window cannot duplicate the same decision
or renew an old ticket. A genuine newer epoch with an equal FS may admit new work;
old physical completion cannot clear or write the new logical slot. Retained
attempt metadata prunes the original Item/session lifetime even if another caller
keeps its filesystem alive. Lifetime excludes profile association/policy validity,
so those transitions do not renew an OS once marker. Workspace event delivery
schedules source reprojection through App::defer after its entity lease ends;
receipt validation remains synchronous at admission/completion. Deferred and
observer callbacks keep weak collaborators, and editor country input retains only
its narrow weak raw-facts service, so callback cleanup cannot keep the installation
alive or recursively unsubscribe its own collection. Initial saved manual country
keys drain through the same scheduler even with empty Known/no live session.

`CountryPolicySource` supplies detection enabled and existing successful published
SettingsHandle revision. Coalesced disable/enable and unrelated successful settings
publication conservatively invalidate country tickets. Same-current-source retries
are bounded by the shared scheduler; unchanged native None/error/manual skips keep
their once-per-real-capability decisions. Profile/epoch changes and policy retries
remain distinct authorities.

A shared 32-slot physical ledger reserves paired OS/location jobs atomically before
marking admission. Invalidating tickets never releases a physical slot early. Weak
rotating source cursors reproject after capacity events; alternating flag/probe lanes
preserve fair retries and a blocked paired reservation. There is no filesystem
payload queue, production worker pool or promise to cancel blocking native calls.

Raw CountryCode flags have their own physical-token authority and bounded immutable
256-KiB payload. Startup persisted country keys, manual saved choices and editor
country drafts require neither a live session nor enabled automatic detection.
OS/DNS/GeoIP require an original connected matching source. Feature-only image
presentation reuses one cached image per country and embedded terminal fallback.
The domain owns values/bounds; existing adapters own native I/O. Known data uses
existing optimistic persistence and common capture/shutdown; closing rejects new
admission and late native result mutation.

## Alternatives rejected

- Final JSON equality or observer delivery alone loses intermediate authority.
- A live FS Arc or a replacement window cannot prove the original session stayed current.
- Early slot release on stale completion violates the physical native-work bound.
- A whole-parent callback, new generic Store hook or settings/global field widens ownership.
- Moving image decoding into the service introduces presentation coupling.

## Consequences

Connection/facts wire formats, manual/offline behavior, retained installation and
shared persistence deadlines remain unchanged. This supersedes feature ownership
of raw-fact scheduling/publication in ADR0027,0039,0043 and the remaining fact-job
placement in ADR0047. Their adapter contracts, terminal capability rules, profile
publication carrier and common capture semantics continue to apply. Accepted ADRs
remain immutable.
