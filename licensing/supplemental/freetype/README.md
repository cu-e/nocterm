# FreeType native-library license

`freetype-sys` 0.20.1 contains FreeType 2.13.2 but omits its referenced
`docs/FTL.TXT`. This file is reproduced from FreeType commit
`920c5502cc3ddda88f6c7d85ee834ac611bb11cc` (release 2.13.2):
<https://github.com/freetype/freetype/blob/920c5502cc3ddda88f6c7d85ee834ac611bb11cc/docs/FTL.TXT>.
The source URL and checksum are recorded in `licensing/sources.json`.

Nocterm selects the FreeType License option for bundled FreeType rather than its
alternative GPL option. The notice generator retains the original terms and the
required acknowledgement: "This software is based in part on the work of the
FreeType Team."
