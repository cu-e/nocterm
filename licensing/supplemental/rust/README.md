# Rust standard-library notices

`COPYRIGHT-library.txt` contains the full rendered text of `COPYRIGHT-library.html`
from the Rust 1.98.0 toolchain distribution, commit
`88d9e12ae178fab0fb5cc050a94da85685d449ea`. Only HTML markup and repeated blank
lines and trailing horizontal whitespace were removed; copyright and license text are retained. The original HTML
checksum appears at the top of the converted file.

Source: <https://doc.rust-lang.org/1.98.0/COPYRIGHT-library.html>.

These notices cover the standard library and its bundled dependencies, which
Cargo metadata does not list. Update this snapshot when changing the release
Rust toolchain in `.github/workflows/package.yml`.
