# Third-party notice sources

`THIRD_PARTY_NOTICES.txt` is generated by
[`scripts/generate-license-notices.py`](../scripts/generate-license-notices.py)
from Cargo dependency metadata, original license and copyright files, vendored
forks, and the snapshots in this directory. See
[packaging instructions](../docs/PACKAGING.md#license-notices) for regeneration.

`sources.json` records the provenance of supplemental snapshots:

| Field | Meaning |
| --- | --- |
| `packages` | Cargo package names and versions (`name@version`) covered by the snapshot; empty for components outside Cargo metadata |
| `path` | Snapshot path relative to this directory |
| `url` | Original source URL, pinned to a version or commit where available |
| `sha256` | SHA-256 of the committed snapshot bytes, checked during generation |
| `source_sha256`, `transformation` | When present, checksum of the original source bytes and description of formatting changes in the snapshot |
| `kind` | `declaration` identifies an original licensing declaration rather than a standalone license file |
| `component`, `version` | Identity of a bundled component outside Cargo metadata, when recorded |

`upstream/` preserves original files retrieved from pinned upstream sources when
published crate archives omit license files. For publishers without a primary
license file, declaration snapshots preserve the original manifest license
expression and any available copyright or license headers. The generator also
includes the corresponding SPDX reference terms. These references do not invent
copyright owners or replace available original notices.

`supplemental/` preserves license texts for nested native components, fonts and
other bundled assets, with adjacent README files describing provenance. In
particular, FreeType's snapshot and acknowledgement match the native version in
`freetype-sys`; review them when that dependency changes. Rust's standard-library
copyright snapshot covers components absent from Cargo metadata and must match
the release Rust toolchain. Update `supplemental/rust/` when changing the Rust
version and regenerate the notices. The fast packaging check includes source
snapshots and toolchain configuration in its input fingerprint.

Review provenance and exact source bytes before updating a snapshot or checksum.
Preserve original copyright notices and all applicable nested license terms.

The RPM metadata uses `LicenseRef-Nocterm-Third-Party` to reference the existing
bundled component terms collected in `THIRD_PARTY_NOTICES.txt`, together with
`LicenseRef-PolyForm-Perimeter-1.0.1` for application code. These references do not
replace component licenses or grant additional rights.

AppImage's separate statically linked launcher is pinned in
[`appimage-runtime.json`](appimage-runtime.json). Its full launcher, libfuse and
squashfuse source archives are fetched into ignored `target/` directories and
included inside each AppImage with
[build and relinking instructions](supplemental/appimage/README.md).
